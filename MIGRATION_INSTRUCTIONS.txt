📝 STEP-BY-STEP INSTRUCTIONS

1. Open Terminal/PowerShell

2. Navigate to project directory:
   cd "D:\[01] PROJECT\HERO"

3. (OPTIONAL) Backup database first:
   pg_dump -U postgres -d hero_db > backup_20260503.sql

4. Run migration:
   psql -U postgres -d hero_db -f db\migrations\add_user_constraints.sql

   Or if using Drizzle:
   npx drizzle-kit push:pg

5. Verify migration success:
   psql -U postgres -d hero_db

   Then run these queries:

   -- Check new tables
   SELECT table_name FROM information_schema.tables 
   WHERE table_name LIKE ''hero_user_%'';

   -- Check new columns
   SELECT column_name FROM information_schema.columns 
   WHERE table_name = ''hero_employees'' 
   AND column_name IN (''deleted_at'', ''email_verified'', ''last_login_at'');

   -- Check indexes
   SELECT indexname FROM pg_indexes 
   WHERE tablename IN (''hero_employees'', ''auth_user'') 
   AND indexname LIKE ''%email%'';

🔧 TROUBLESHOOTING

If migration fails:

1. Check PostgreSQL is running:
   pg_isready

2. Check database exists:
   psql -U postgres -l | findstr hero_db

3. Check connection:
   psql -U postgres -d hero_db -c "SELECT 1;"

4. If duplicate email error:
   - Migration will auto-rename duplicates
   - Check renamed emails: SELECT email FROM hero_employees WHERE email LIKE ''%.dup%'';
   - Manually fix duplicates later

5. If permission error:
   - Run as database owner
   - Or grant permissions: GRANT ALL ON DATABASE hero_db TO your_user;
