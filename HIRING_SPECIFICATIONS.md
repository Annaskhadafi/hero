## Appendix: Interview Questions

### Full-Stack Engineer Questions

**Technical:**
1. Explain the difference between Server Components and Client Components in Next.js 13+.
2. How would you optimize a slow database query with multiple joins?
3. Design a real-time notification system for 500+ concurrent users.
4. How do you handle file uploads in a Next.js app? (S3, presigned URLs, etc.)
5. Explain your approach to error handling in API routes.

**System Design:**
1. Design a daily report generation system that processes 100+ reports per day.
2. How would you implement offline-first sync for a mobile PWA?
3. Design a point calculation system with multiple rules and modifiers.

**Code Review:**
1. Review this code snippet and identify issues. (Provide sample code)
2. How would you refactor this component for better testability?

### QA Engineer Questions

**Technical:**
1. What's your approach to testing a mobile-first PWA?
2. How do you decide what to test manually vs. automate?
3. Explain the testing pyramid and how you apply it.
4. How do you test API endpoints with authentication?
5. What metrics do you track for test coverage and quality?

**Practical:**
1. Write test cases for a login flow with email/password.
2. How would you test a file upload feature?
3. Describe your bug report template.

### DevOps Engineer Questions

**Technical:**
1. How would you set up a CI/CD pipeline for a Next.js app?
2. Explain your approach to zero-downtime deployments.
3. How do you monitor application performance in production?
4. What's your strategy for database backups and disaster recovery?
5. How do you secure a web application? (HTTPS, headers, secrets, etc.)

**System Design:**
1. Design production infrastructure for a 500-user web app.
2. How would you handle a sudden traffic spike (10x normal load)?
3. Explain your incident response process.
